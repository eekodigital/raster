## Install

```sh
pnpm add @eekodigital/raster
```

`react` and `react-dom` 19 are peer dependencies. If you use GeoChart, also install its optional peer:

```sh
pnpm add topojson-client
```

## Load the stylesheet once

Raster ships one stylesheet. Import it once at your app root, before your own styles:

```ts
import "@eekodigital/raster/styles.css";
```

No chart imports CSS itself, so the package's `sideEffects` lists only the stylesheet: bundlers can drop any chart you don't use, but keep the stylesheet import. If the stylesheet is missing, charts still render: marks get their colours from attributes, and the visually hidden summary and title keep an inline visually-hidden style (the data table stays hidden until its button is pressed). Animations, focus rings and the default grid and axis styling do need it.

## Server rendering and React Server Components

Every chart renders on the server: the figure, summary, data table and named marks are in the HTML before any JavaScript runs.

With React Server Components (the Next.js App Router), the entries that export components start with `"use client"`, so you can import a chart straight into a Server Component page. `"use client"` doesn't stop server rendering. The chart is still rendered to HTML on the server; it only marks where the browser takes over (hydration) for keyboard, tooltips and selection.

A few props can't be passed from a Server Component, because they hold functions, which can't cross from server to client:

- `x={timeAxis(…)}`, `formatValue`, `formatX`, `formatXTick`, `onSelect` and other callbacks
- `labels` with function overrides (`summary`, `mark`, …)

Put a chart that needs them in a small client component of your own (a file starting with `"use client"`), and pass it plain data from the server. `timeAxis` (`/time`), `exportSVG` (`/export`), `describeChart` (`/labels`) and `rasterVars` (`/theme`) aren't marked, so server code can call them. Import `describeChart` from `/labels` in a Server Component: the main entry and `/frame` are marked. TypeScript won't catch a function prop passed from a Server Component; the framework reports it when the page renders.

### Vite

In development, Vite discovers each raster entry the first time a page imports it, and reloads the page to optimise it. To skip those reloads, list the entries you use:

```ts title="vite.config.ts"
export default defineConfig({
  optimizeDeps: {
    include: ["@eekodigital/raster", "@eekodigital/raster/time", "@eekodigital/raster/export"],
  },
});
```

## Fonts, colour and spacing

Charts inherit `font-family` and `color` from where you render them, so they pick up your typography with no configuration. Spacing is internal. To match your colours, map your tokens onto raster's contract; see [Theming charts](/guides/theming/).
