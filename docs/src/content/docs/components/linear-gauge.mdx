## Accessibility

- `role="meter"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow` and `aria-valuetext` from `format`.
- Named by the visible `label` through `aria-labelledby`.
- Fills its container's width; the grow animation stops under `prefers-reduced-motion`.

See the <a href="/guides/accessibility/">Accessibility guide</a> for the shared structure, the `labels` prop and screen-reader testing.
