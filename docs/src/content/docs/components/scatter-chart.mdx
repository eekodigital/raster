## Reference lines

`referenceLines` draws dashed, labelled lines: across y by default, or vertical at an x value with `axis: "x"`. Both scales stretch to include them. The x value is worded with `formatX`. They're named in the summary and the table caption, and aren't focusable.

```tsx
<ScatterChart
  data={points}
  referenceLines={[
    { value: 4.5, label: "Pass mark" },
    { value: 60, label: "Time limit", axis: "x" },
  ]}
  title="Score against time taken"
/>
```

## Accessibility

- A `role="figure"` named by the visible `title` and described by a generated summary (chart type, series and point counts, range).
- The SVG is a `role="group"` with `aria-roledescription="chart"`; no `graphics-*` roles.
- Named series are `role="group"`s. Each point is labelled `{series}, {x}: {y}, 3 of 12` (with its `label` when given). With `onSelect`, `selectedIndex` or a click handler, marks are `role="button"` with `aria-pressed`; otherwise they're static `role="img"`.
- Points use a different marker shape per series.
- Arrow keys move in x order, so left and right match the drawing.
- A visible **Show data table** button (`aria-expanded`) reveals a real table captioned `Data for {title}`, with `th scope` headers and values run through `formatX` and `formatValue`.
- Escape (inside the chart only) clears the selection and announces it in a polite live region; it doesn't close a surrounding dialog.
- Animations stop under `prefers-reduced-motion`. In forced-colours mode marks use system colours, told apart by dash pattern and marker shape.

| Key               | Action                               |
| ----------------- | ------------------------------------ |
| ← / →             | Previous / next mark                 |
| Home / End        | First / last mark                    |
| PageUp / PageDown | Back / forward 10 marks              |
| ↑ / ↓             | Previous / next series               |
| Tab               | Leave the chart (one tab stop)       |
| Enter / Space     | Toggle selection (interactive marks) |
| Escape            | Hide the tooltip and clear selection |

See the <a href="/guides/accessibility/">Accessibility guide</a> for the shared structure, the `labels` prop and screen-reader testing.
