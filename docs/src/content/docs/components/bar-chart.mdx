## Basic

Pass data as an array of `{ label, value }` objects. Colours default to the raster series palette (`--raster-series-*`) or can be set per bar with `colors`.

<Example
  code={`import { BarChart } from '@eekodigital/raster';\n\n<BarChart\n  data={[\n    { label: 'Pass', value: 42, color: 'var(--demo-good)' },\n    { label: 'Fail', value: 8, color: 'var(--demo-bad)' },\n    { label: 'N/A', value: 12, color: 'var(--demo-neutral)' },\n    { label: 'To do', value: 24, color: 'var(--demo-warn)' },\n  ]}\n  title="Conformance results by status"\n/>`}

## Stacked, with selection

For several series, pass `series` (`{ name, data }`, as on LineChart) with `categories`. They're grouped side by side, or `stacked`. With `onSelect`, bars become toggle buttons, and selecting one selects that bar (`{ series, point }`).

<Example
  code={`<BarChart\n  series={[\n    { name: 'North', data: [12, 15, 9] },\n    { name: 'South', data: [8, 11, 14] },\n  ]}\n  categories={['Q1', 'Q2', 'Q3']}\n  stacked\n  title="Sales by region (select a bar)"\n  selectedIndex={selected}\n  onSelect={setSelected}\n/>`}
>
  <BarChartSelectDemo client:load />
</Example>

## Reference lines

`referenceLines` draws dashed, labelled lines across the value axis: vertical for `direction="horizontal"`. The value scale stretches to include each line. They're named in the summary and the table caption, and aren't focusable. See [LineChart's reference lines](/components/line-chart/#reference-lines) for wording and styling.

<Example
  code={`<BarChart\n  data={days}\n  referenceLines={[{ value: 40, label: 'Daily goal' }]}\n  title="Issues fixed this week"\n/>`}

</Example>

## Accessibility

- A `role="figure"` named by the visible `title` and described by a generated summary (chart type, series and point counts, range).
- The SVG is a `role="group"` with `aria-roledescription="chart"`; no `graphics-*` roles.
- Each bar is labelled `{x}: {y}, 2 of 4` (several series: `{series}, {x}: {y}, 2 of 4`, inside a `role="group"` per series). With `onSelect`, `selectedIndex` or a click handler, marks are `role="button"` with `aria-pressed`; otherwise they're static `role="img"`.
- A visible **Show data table** disclosure (a native `<details>`/`<summary>`, so it opens without JavaScript) reveals a real table captioned `Data for {title}`, with `th scope` headers and values run through `formatValue`.
- Escape (inside the chart only) hides the tooltip and clears the selection, announcing the cleared selection in a polite live region; it doesn't close a surrounding dialog.
- Animations stop under `prefers-reduced-motion`. In forced-colours mode bars use system colours; with several series, series after the first are outlined with their legend line's dash pattern.

| Key                                                        | Action                               |
| ---------------------------------------------------------- | ------------------------------------ |
| ← / → (↑ / ↓ when horizontal)                              | Previous / next mark                 |
| Home / End                                                 | First / last mark                    |
| PageUp / PageDown                                          | Back / forward 10 marks              |
| ↑ / ↓ (stacked: ↑ climbs the stack; ← / → when horizontal) | Previous / next series               |
| Tab                                                        | Leave the chart (one tab stop)       |
| Enter / Space                                              | Toggle selection (interactive marks) |
| Escape                                                     | Hide the tooltip and clear selection |

See the <a href="/guides/accessibility/">Accessibility guide</a> for the shared structure, the `labels` prop and screen-reader testing.
